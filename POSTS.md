Excited to open-source gh-slack-teams-notifier — a small, self-hosted Node.js (18+) service to forward GitHub webhook events to Slack and Microsoft Teams.

What it does
• Route each repo to its own channel(s)
• Filter events per channel (PRs, issues, releases, failed CI)
• Verify GitHub webhook signatures
• Zero dependencies — runs on Node 18+

It’s a lightweight alternative you fully control.
Repo: https://github.com/Kaptaan91/gh-slack-teams-notifier
Feedback and PRs welcome.

Note: This project has only been validated with mocked webhook payloads. Real Slack and Teams testing is recommended before production use.
